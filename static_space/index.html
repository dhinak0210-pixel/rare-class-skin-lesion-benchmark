📦 Quickstart: Load from Hugging Face Hub

You can programmatically load the pre-trained weights in PyTorch using the standard Hugging Face Hub library:

from huggingface_hub import hf_hub_download
import torch

# 1. Download model weights from Hugging Face Model Hub
model_path = hf_hub_download(
    repo_id="dhina0210/rare-class-skin-lesion-benchmark",
    filename="best_model.pt"
)

# 2. Load PyTorch checkpoint
checkpoint = torch.load(model_path, map_location="cpu")
print("Checkpoint loaded successfully!")
print("Num classes:", checkpoint.get("num_classes", 7))
print("Best test balanced accuracy:", checkpoint.get("test_bal_acc", 0.72))
