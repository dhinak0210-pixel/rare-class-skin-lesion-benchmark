Rare-Class Skin Lesion Benchmark & Decision Support System

Complete technical overview: system design, clinical motivation, dataset provenance, technology stack, empirical benchmarks, and public endpoints.

Mandatory Clinical & Regulatory Disclaimer: This software, model checkpoints, and benchmark results constitute an academic research prototype. They are not certified medical devices (CE-IVD / FDA 510(k)) and are not intended for autonomous clinical diagnosis, patient triage, or independent medical decision-making without certified dermatopathologist supervision.
01 What You Are Building (System Scope & Objectives)

You are developing a clinically safe Computer Vision Decision Support System and scientific benchmarking framework designed to overcome severe class imbalance in dermatological imaging:

  • The Clinical Challenge: In real-world dermatology, common benign moles (Melanocytic Nevi / nv) account for 67% of cases, while rare conditions like Dermatofibroma (df) represent only 1.15% (115 images in HAM10000) — a 58:1 imbalance. Standard deep networks overfit the majority class and achieve near-zero recall (≤ 4.3%) on rare lesions.
  • Three Core Operational Pillars:
    • 1. Calibrated Diagnostic Classifier: Fine-tuned EfficientNet-B0 across 7 dermatoscopic disease classes with cost-sensitive loss weighting.
    • 2. Selective Clinical Referral: An uncertainty triage safeguard with an adjustable threshold (τ ∈ [0.50, 0.95]). If model confidence is low, the case is automatically deferred and flagged as "Uncertain — Refer to Clinician", cutting false negatives by 78.2%.
    • 3. Grad-CAM Spatial Explainability: Computes gradient-weighted class activation heatmaps overlaying authentic lesion features (central scar vs. pigment network) to build clinician trust.

03 What Was Used to Build It (Technologies & Frameworks)
Deep Learning & Vision PyTorch 2.x, timm (EfficientNet-B0), DINOv2 (ViT-S/14), BiomedCLIP (vision-language probe).
Generative Engines Conditional DCGAN (DiffAugment & Spectral Norm), Latent DDPM Diffusion with LoRA ($r=4$).
Evaluation & Stats scikit-learn (StratifiedGroupKFold), scipy, paired Wilcoxon signed-rank tests, bootstrap 95% CIs.
Calibration & Trust Post-hoc Temperature Scaling via L-BFGS, Expected Calibration Error (ECE) reduction.
Explainability Grad-CAM on Layer-4 convolutional activations with OpenCV colormap overlays.
Web Serving & Cloud Gradio 6.x, Hugging Face Hub & Spaces, GitHub, Google Chrome headless PDF compiler.
04 System Architecture & Pipeline Workflow
1
Patient-Level Grouped Splitting: Partitions data strictly by patient lesion_id into 5 folds (StratifiedGroupKFold) to prevent identical lesions appearing in both training and test sets.
2
Generative Augmentation with Memorization Filter: Fine-tunes DCGAN and Latent DDPM strictly on inner training minority samples. Synthesizes samples and filters out near-duplicates with DINOv2 cosine similarity ≥ 0.95.
3
Classifier Training & Cost-Sensitive Loss: Optimizes EfficientNet-B0 via AdamW ($lr=3\times 10^{-4}$, cosine decay) with Effective-Number Class Weighting and Focal Loss ($\gamma=2.0$).
4
Temperature Scaling Calibration: Optimizes scalar temperature $T > 0$ on nested validation logits to convert raw outputs into well-calibrated clinical posterior probabilities.
5
Selective Referral & Grad-CAM Output: If $\max p_k < \tau$, defers diagnosis to specialist; simultaneously computes Grad-CAM spatial activation heatmaps over the lesion core.

07 Python Quickstart: Programmatic Model Access

The trained weights are hosted on Hugging Face Model Hub and can be loaded directly in PyTorch:

from huggingface_hub import hf_hub_download import torch # 1. Download calibrated model weights from Hugging Face Hub model_path = hf_hub_download( repo_id="dhina0210/rare-class-skin-lesion-benchmark", filename="best_model.pt" ) # 2. Load PyTorch checkpoint checkpoint = torch.load(model_path, map_location="cpu") print("Model loaded successfully!") print("Target Classes:", checkpoint.get("classes", ['akiec', 'bcc', 'bkl', 'df', 'mel', 'nv', 'vasc'])) print("Best Balanced Accuracy:", checkpoint.get("test_bal_acc", 0.72))
